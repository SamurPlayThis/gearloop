# GEARLOOP — Telegram Mini App prototype

Изометрическая браузерная игра-прототип + Telegram-бот для открытия Mini App.

## Что уже работает
- Изометрическая игровая сцена в пиксельном/low-res стиле.
- Несколько отдельных фабрик с открытием за монеты.
- Размещение добытчиков, конвейеров, прессов, сборщиков и пунктов отгрузки.
- Выбор станка, улучшение и удаление с частичным возвратом стоимости.
- Простой цикл производства, ресурсы, монеты и сохранение в localStorage.
- Адаптация под мобильный экран и Telegram WebApp SDK.

## Запуск в браузере
Открой `web/index.html` в браузере. Для локального сервера:
```bash
cd web
python -m http.server 8000
```
Затем открой `http://localhost:8000`.

## Подключение Telegram
1. Создай бота через @BotFather.
2. Размести содержимое папки `web` на HTTPS-хостинге (например, GitHub Pages, Cloudflare Pages или Vercel).
3. Установи зависимости: `pip install -r requirements.txt`.
4. Задай переменные окружения `BOT_TOKEN` и `WEBAPP_URL`.
5. Запусти `python bot.py`.
6. В @BotFather настрой домен Mini App для своего бота.

Пример:
```bash
# Linux/macOS
export BOT_TOKEN="токен_от_BotFather"
export WEBAPP_URL="https://твой-домен/"
python bot.py
```

## Важно перед публичным запуском
Это первый рабочий прототип, а не production-версия. Сейчас прогресс хранится локально в браузере игрока. Для реального мультиустройства, рейтингов, защиты экономики и Premium нужно добавить сервер/API, базу данных, проверку Telegram `initData` на сервере и платежную обработку Telegram Stars. Никогда не помещай токен бота в HTML/JavaScript и не публикуй его.


## Premium

Реальная покупка пока не подключена: для неё нужен серверный endpoint создания Telegram Stars invoice, обработчики `pre_checkout_query` и `successful_payment`, проверка платежа и хранение статуса подписки в базе данных. Кнопка оплаты в прототипе честно сообщает, что платёжная интеграция ещё не готова.
